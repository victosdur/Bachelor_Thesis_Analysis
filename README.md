This repository contains the data, analysis, and slides for my Statistics Bachelor thesis "Indicadores estadísticos asociados a la encuesta de condiciones de vida".

You can find the original document here: https://idus.us.es/items/9be13c6a-8770-4e3c-bf99-70ebca4941d1

The "PresentacionDiapositivasInteractiva_TFG.Rmd" document is a interactive shiny app, which serves to communicate, illustrate and defend the thesis. There you can see some important explanations, as well as the performed analysis and results, on a interactive way. Please run it to have it deploy locally.
